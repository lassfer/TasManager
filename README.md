# 📊 Система учета задач (Task Tracker Enterprise)

Современная модульная панель мониторинга и распределения задач по проектам. Программа связывает между собой проекты, задачи, исполнителей и комментарии в единый сквозной процесс, обеспечивая высокую скорость работы и полную защиту данных от сетевых сбоев.

---

## 🏗️ Из чего состоит система (Архитектура и Порты)

Проект разбит на независимые изолированные модули (контейнеры), которые общаются друг со другом внутри сети Docker:

1. **Главный диспетчер (Оркестратор):** Написан на `Node.js / Express`. Собирает запросы с сайта, проверяет правила и управляет процессом (Порт `5003`).
2. **Модуль сотрудников:** Написан на `Python`. Отвечает за выгрузку и проверку исполнителей (Порт `8080`).
3. **Модуль комментариев:** Написан на `Node.js`. Отвечает за фиксацию истории и системных логов (Порт `5002`).
4. **Постоянная база данных:** `PostgreSQL 15`. Надежно хранит все таски, связи и проекты на жестком диске (Порт `5432`).
5. **Быстрый кэш памяти:** `Redis`. Хранит списки сотрудников в оперативной памяти для мгновенной загрузки (Порт `6379`).

---

## 🎯 Ключевые фичи и логика защиты

- **Контроль цепочки данных:** Если при создании задачи падает один из модулей (например, завис сервис комментариев), система автоматически делает откат изменений. База данных PostgreSQL очищается от битых записей, а задача переводится в статус `Cancelled` (Отменено), сохраняя порядок в системе.
- **Предохранитель (Circuit Breaker):** Если сторонний модуль падает три раза подряд, система временно блокирует к нему запросы на 30 секунд, защищая сервер от лишней нагрузки.
- **Ускорение через Кэш:** Список сотрудников не дергает тяжелую базу данных при каждом клике, а мгновенно забирается из быстрой памяти Redis за ~45 мс.

## 🚀 Пошаговый запуск на компьютере

### Шаг 1. Предварительные требования
Убедитесь, что на компьютере установлена и запущена программа **Docker Desktop**.

### Шаг 2. Скачивание и чистая сборка контейнеров
Откройте терминал (PowerShell или Git Bash) в папке проекта и запустите команду очистки и пересборки «с нуля»:
```bash
docker compose down --volumes --remove-orphans
docker compose up -d --build
```
*Docker автоматически скачает нужные базы данных, скомпилирует твой код на Node.js/Python и поднимем всю сеть.*

### Шаг 3. Запуск веб-интерфейса
Откройте любой браузер и перейдите по адресу:
👉 **http://localhost:5003**

## 🧪 Запуск автоматических тестов (Локально)

Перед отправкой кода на GitHub рекомендуется проверить стабильность маппинга и роутов. Для этого в терминале VS Code введите:
```bash
npm install
npm test
```
*Запустится тестовый фреймворк Jest, который прогонит юнит- и интеграционные тесты через изолированные заглушки (Mocks) меньше чем за секунду.*
